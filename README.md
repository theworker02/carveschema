# carveschema

Carve validation gates for schema inputs before they hit prod.

**Site:** https://theworker02.github.io/carveschema/

## Install / run

```bash
git clone https://github.com/theworker02/carveschema.git
cd carveschema
node src/cli.js
node --test
```
